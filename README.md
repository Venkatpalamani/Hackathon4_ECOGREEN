PROJECT : ECOGREEN

Problem Statement:
Zero Waste – Turn a waste stream into a desirable product or service brand.

BRAND NAME : ECOGREEN

WORKING MODEL :

1. COLLECTING RAW MATERIALS
   ECOGREEN collects reusable waste from:
   - Temples → Used Flowers, Coconut Waste
   - Hotels → Used Soaps, Used Brushes
   - Shops → Sugarcane Waste, Used Clothes 
   ETC....

2. SELL RAW MATERIALS
   Sellers can upload waste details through our website:
   - Select Raw Material
   - Enter Quantity (KG)
   - Upload Waste Photos
   - Enter Expected Price
   - Submit Request

3. BRAND MANAGER
   The Brand Manager reviews the request and can:
   - Accept / Reject the Request
   - View Waste Details & Photos
   - Send Confirmation to the Seller

4. WASTE → PRODUCTS
   - Sugarcane Waste → Paper Cups / Plates / Biodegradable Covers
   - Used Flowers → Agarbatti / Dhoop Sticks
   - Used Soaps → Reprocessed Soaps
   - Coconut Waste → Kitchen Scrubs
   - Used Clothes → Recycled Cloth Products

5. BUY PRODUCTS
   Customers can:
   - Browse ECOGREEN Products
   - View Product Details & Price (₹)
   - Add Products to Cart
   - Place Orders

6. COMPLETE CYCLE

   Waste Producers
          ↓
   Sell Raw Materials
          ↓
   ECOGREEN
          ↓
   Process & Manufacture
          ↓
   ECOGREEN Products
          ↓
   Customers Buy Products

GOAL :
Convert waste into useful products, reduce waste,
and provide affordable eco-friendly alternatives.
